// BEFORE GO-LIVE

Deployment Checklist

All four requirements must be met before staking transactions are activated.

  1. 01
    Verify Green Flock Collection

    Confirm collection address, ERC-721 standard, metadata URI, and 1–3333 token inventory on Robinhood Chain.

  2. 02
    Publish Rarity Mapping

    Place token ID → tier on-chain or commit a final verified mapping before deployment. All 3333 IDs must be covered exactly once.

  3. 03
    Deploy & Audit Staking Contract

    Deploy contract with stake / unstake / claimReward / pendingReward. Use OpenZeppelin ReentrancyGuard + SafeERC20. Audit before mainnet.

  4. 04
    Fund Reward Vault

    Transfer $ROBINPUMP to the staking contract reward vault. Verify on-chain balance before opening staking to the public.
